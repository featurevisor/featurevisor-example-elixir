# featurevisor-example-elixir

A small Elixir application showing how to consume the published [Featurevisor Elixir SDK](https://github.com/featurevisor/featurevisor-elixir) from Hex.pm.

The application downloads a Featurevisor datafile, creates an SDK instance, and evaluates one feature as a flag, variation, and string variable.

## Requirements

Elixir 1.15 or newer.

## Installation

```sh
mix deps.get
```

## Run it

```sh
mix run -e 'FeaturevisorExampleElixir.run()'
```

The application fetches this production datafile:

```text
https://featurevisor-example-cloudflare.pages.dev/production/featurevisor-mobile.json
```

The important SDK usage is in `lib/featurevisor_example_elixir.ex`:

```elixir
f = Featurevisor.create_featurevisor(%{
  datafile: datafile,
  context: %{
    "userId" => "mobile-user",
    "country" => "nl"
  }
})

enabled = Featurevisor.enabled?(f, "mobile_experience")
variation = Featurevisor.get_variation(f, "mobile_experience")

welcome_message =
  Featurevisor.get_variable_string(
    f,
    "mobile_experience",
    "welcome_message"
  )

Featurevisor.close(f)
```

The `featurevisor` dependency comes from Hex.pm. It is not a local path dependency, so this project demonstrates the same setup used by a new consumer.

Learn more in the [Featurevisor Elixir SDK documentation](https://featurevisor.com/docs/sdks/elixir/).

## Featurevisor project

The datafile is generated by the [Featurevisor example Cloudflare project](https://github.com/featurevisor/featurevisor-example-cloudflare).
